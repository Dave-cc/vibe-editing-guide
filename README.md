# Vibe 剪辑入门

用一张嘴指挥 AI 剪片。

Vibe 剪辑就是用嘴剪片：你把想要的效果用人话说出来，AI 动手做。纯代码画出来的知识短片、产品动效、拼贴拆解、口播精剪，现在都已经可以这么做。

现阶段它最大的瓶颈不在 AI，在你没办法有效地描述出想要的画面，而描述靠的是储备：有哪些画风，什么叫景别，光和颜色怎么说，镜头可以怎么动，剪辑有哪些手法。这些东西你得先知道有，需要的时候才用得出来。这份手册就是来补这个信息差的，每个知识点讲四件事：是什么，为什么，怎么对 AI 说，怎么用得更好。

模型的能力会不断追平，今天只有顶级模型做得到的事，以后普通模型也做得到。这里教的是“怎么看、怎么说”，换哪个模型都用得上。

手册会持续更新，欢迎提 issue 一起补。

## 两种读法

**只想要效果和指令**：直接看 [一键动效 Prompt](docs/recipes.md)。三十多个带动态预览的效果，每个下面是可以复制给 AI 的指令；另有六份整片 Prompt和十句改片常用话。

**想弄明白为什么**：从头读。

| 部分 | 章节 | 讲什么 |
|---|---|---|
| 开始 | 这份手册怎么用、一条视频的解剖 | AI 是怎么剪片的；帧、轨道、A-roll/B-roll、关键帧 |
| 镜头语言 | 景别角度构图、光与色、运镜 | 一帧画面里能调的全部东西，以及镜头怎么动 |
| 剪辑 | 切点与连贯、蒙太奇节奏转场、声音 | 在哪切、接什么、留多久、声音怎么配 |
| 动效 | 动效的底层规律、文字图形片头、画风图鉴 | 缓动、时长、进场方式；二十种常见画风 |
| 审美 | 向导演和频道学、什么叫好、排片 | 好片子的六条标准、拉片方法、什么内容用什么形式 |
| 落到嘴上 | 一键动效 Prompt、对 AI 说话、术语速查、片单与出处 | 指令模板、感觉词翻译表、改片话术 |

## 仓库结构

```
index.html 等 18 个页面    构建好的成品，直接打开或用 Pages 托管
src/                      每一章的正文（HTML 片段）
assets/
  site.css  site.js       样式和交互演示
  recipes.js              一键动效 Prompt里的预览动画
  template.html           页面模板
  img/  video/            片例截图和短片段
build.py                  把 src/ 拼成成品页面
```

## 修改内容

改 `src/` 里对应章节的文件，然后运行：

```bash
python build.py
```

只依赖 Python 3 标准库。脚本会重新生成根目录下的页面，并报告缺失的素材。

章节正文是普通 HTML，另有几个简写标签：

| 写法 | 生成 |
|---|---|
| `<fig src="x.jpg" cap="说明" from="出处"/>` | 带说明的图片（文件放 `assets/img/`） |
| `<vid src="x.mp4" cap="说明" from="出处"/>` | 静音循环的片段；加 `sound="1"` 为有声 |
| `<ai><no>…</no><yes>…</yes><why>…</why></ai>` | “对 AI 这样说”对照框 |
| `<rx demo="名字" t="标题" use="用在哪">指令</rx>` | 一键动效 Prompt的卡片 |
| `<note>` `<tip>` `<warn>` | 提示框 |
| `<term en="English">中文</term>` | 带英文的术语 |

导航和章节顺序在 `build.py` 顶部的 `NAV` 里。

## 关于准确性

手册里有出处的事实（比如剪辑六原则的权重出自沃尔特·默奇的《眨眼之间》）已注明来源。动效时长、语速、音量关系、安全区比例这类数字是行业通行的经验值，用来起步，不是标准。一键动效 Prompt里的指令按“AI 能照着执行”来写，实际效果会随素材和所用工具有出入。
